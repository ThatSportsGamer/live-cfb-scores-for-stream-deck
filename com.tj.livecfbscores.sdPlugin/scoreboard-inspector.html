How it works:
• Place this action on as many keys as you want — each key is one game
• Shows this week's games in kickoff order (or by ranking); the week moves on Monday at 3:00 AM ET
• Live games show possession and the red zone, flash on every score, and show the play (TD +6, XP +1, FG +3, SAF +2, 2PT +2)
• Keys refresh every 30 seconds (every 15 in the two-minute timeout)
• Press any key to open that game in ESPN Gamecast (the box score once it's final)
• Changes here apply to this whole board: the block of Scoreboard keys this key is part of
Different boards on different pages: set up an SEC page, a Big Ten page and a Top 25 page — each page's keys remember their own choice. Two boards can share a page too, as long as their keys don't touch. New Scoreboard keys start on the Top 25. Each Stream Deck you use gets its own board.
